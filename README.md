TaskFlow

TaskFlow est un projet réalisé dans le cadre du TP du cours IDE & Frameworks.
C’est une application web de gestion de tâches en équipe développée avec React et Vite.

Réalisé par : Leutchouang Chris Darling
Niveau : L3 Sécurité & Cryptographie ENSPM-INFOTEL
Enseignant : Yves Hermann

Installation et lancement du projet

Avant de lancer l’application, il faut d’abord installer les dépendances avec la commande :

npm install

Ensuite, démarrez le serveur de développement avec :

npm run dev

Après le lancement, ouvrez votre navigateur à l’adresse suivante :

http://localhost:5173

Fonctionnalités de l’application

L’application permet de :

- afficher la liste des tâches
- ajouter une nouvelle tâche
- consulter les détails d’une tâche en cliquant dessus
- sauvegarder automatiquement les tâches même après le rechargement de la page

les languagues utiliser sont

- React
- Vite
- JavaScript
- CSS
